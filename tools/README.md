# Tools

Внутренние **исполняемые** инструменты Uplab, которые вызывают агенты (CLI, шаблоны, assets). Это не внешний «vendor» и не паспорт агента — только код и артефакты генерации.

| Каталог | Агент / skill |
| ------- | ------------- |
| `uplab-slide-generator/` | `brand-presentation-maker`, skill `uplab-presentation-generation` |

Методички и примеры Excel-книг лежат в `skills/excel-workbook-generation/guide/` и `examples/`, не здесь.

Учёт **внешних** источников skills — в `skills/attribution/`.
