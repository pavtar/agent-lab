# brand-presentation-maker

Создатель презентаций в фирменном стиле.

## Задача

На основе темы, структуры и бренд-документации подготовить черновик презентации: логика, слайды, тексты, визуальные правила.

## Когда нужен SDK

SDK нужен, если презентации должны создаваться повторяемо из одной папки бренд-документации и сохраняться как артефакты.

## Первый результат

Markdown-структура презентации или JSON-план слайдов. Генерацию `.pptx` лучше делать отдельным этапом после утверждения структуры.

## Входные данные

- Папка с фирменной документацией.
- Тема презентации.
- Аудитория.
- Цель выступления.
