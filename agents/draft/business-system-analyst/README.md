# business-system-analyst

Бизнес и системный аналитик: превращает идею, встречу или описание проблемы в требования, процессы и постановки задач.

## Задача

Сформулировать понятные артефакты: BRD, user stories, карту процесса, риски, вопросы к заказчику и критерии готовности.

## Когда нужен SDK

Часто достаточно Cursor Agent в интерфейсе. SDK нужен, если нужно пакетно обрабатывать документы или регулярно выпускать артефакты по шаблону.

## Первый результат

Черновик ТЗ или BRD по одному проекту.

## Входные данные

- Идея или описание проблемы.
- Заметки встреч.
- Ограничения бизнеса.
- Существующие документы проекта.
