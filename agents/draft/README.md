# Черновики агентов

Здесь паспорта агентов, с которыми **ещё не вышли на первый полезный результат** в рабочем цикле (см. `docs/agent-roadmap.md`). В `npm run agents:list` они выводятся отдельным блоком «Черновики». Проверка: `npm run agent:check -- meeting-secretary` и т.д.

Перенос в `draft/` — только навигация в репозитории; содержимое паспортов можно дорабатывать как обычно.
