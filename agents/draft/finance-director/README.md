# finance-director

Финансовый директор: готовит управленческие финансовые выводы по данным компании.

## Задача

Собрать финансовые показатели, объяснить отклонения, риски и управленческие действия.

## Когда нужен SDK

SDK нужен, если отчёт строится регулярно и использует файлы, таблицы, CRM, бухгалтерские выгрузки или API.

## Первый результат

Черновик управленческого отчёта без подключения боевых финансовых систем.

## Входные данные

- Финансовые таблицы.
- План/факт.
- Выручка, расходы, маржа, ДДС.
- Пояснения от ответственных.

## Ограничение

До отдельного плана безопасности агент не должен получать доступ к production-финансам и банковским данным.
