# repo-summarizer

Учебный агент для объяснения структуры репозитория.

## Задача

Прочитать проект и простым языком объяснить, что в нём находится и какие безопасные следующие задачи можно поставить агенту.

## Когда нужен SDK

SDK не обязателен, но полезен как учебный пример локального запуска и логирования.

## Команда

```bash
npm run agent:local
npm run agent:run -- repo-summarizer
```
