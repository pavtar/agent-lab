# Eval checklist

- Агент ведёт тренировку по Toyota Kata, а не даёт обычные бизнес-советы.
- Первый сценарий — `manager_training`.
- Есть короткая рабочая ситуация.
- Пользователь должен сам сформулировать коучинговый вопрос.
- Агент оценивает вопрос: помогает ли он думать или подсказывает решение.
- Агент предлагает более сильную формулировку вопроса.
- В оценке используются элементы Toyota Kata: target condition, current condition, obstacle, next experiment.
- Агент не обвиняет пользователя и не превращает ответ в лекцию.
- В конце сессии есть короткий разбор и практика на завтра.
- Не требуются секреты, API keys или SDK.

## kata_assistant

- Ответ короткий и понятный для начинающего руководителя.
- Объяснение связано с Toyota Kata, Improvement Kata или Coaching Kata.
- Термины не смешиваются: challenge, current condition, target condition, obstacle, experiment.
- Агент рекомендует подходящий следующий сценарий.
- Агент даёт ссылки на релевантные файлы `knowledge/toyota-kata/`.
- Агент не подменяет специализированные сценарии полноценной сессией.

## team_playbook

- Playbook привязан к конкретной команде и процессу.
- Есть роли: sponsor, coach, learner, при необходимости second coach.
- Есть ритм на 4-6 недель.
- Есть артефакты: Карта событий ученика, PDCA, список препятствий.
- Есть первый пилот и критерии успеха.
- Еженедельная сессия не описана как статус-митинг.
- Есть следующий шаг на ближайшую неделю.
- Риски внедрения описаны вместе с профилактикой.

## problem_improvement

- Разбор привязан к конкретной бизнес-проблеме и процессу.
- Есть challenge или направление.
- Current condition описан фактами, метриками, наблюдениями и неизвестными зонами.
- Target condition описывает состояние на ближайший горизонт, а не список действий.
- Есть список obstacles.
- Выбрано одно препятствие в работу: one obstacle now.
- Next experiment содержит гипотезу, шаг, ожидаемый результат и срок проверки.
- Агент фиксирует, что нужно узнать до следующего цикла.
- Агент не перепрыгивает к готовому решению или проектному плану.
