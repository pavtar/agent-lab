# spreadsheet-maker

Создатель таблиц по документации, шаблону или бизнес-задаче.

## Задача

Создавать полноценные управленческие Excel-книги `.xlsx`: листы, колонки, оформление, инструкции, историю версий, проверки и понятную структуру для команды.

## Skills

- `skills/excel-workbook-generation/SKILL.md` — методика создания управленческих `.xlsx` книг.

## Когда нужен SDK

Для первой версии SDK не нужен: агент запускается вручную через Cursor Agent и создаёт файл по конкретной задаче.

SDK понадобится позже, если таблицы нужно регулярно создавать по шаблонам, проверять структуру или обрабатывать набор файлов.

## Первый результат

Файл `outputs/spreadsheet-maker/План внедрения операционной модели агентов v1.0.xlsx`.

## Входные данные

- Документация и примеры: `skills/excel-workbook-generation/guide/` и `skills/excel-workbook-generation/examples/`.
- Skill: `skills/excel-workbook-generation/SKILL.md`.
- Цель таблицы.
- Пользователь таблицы.
- Пример существующей таблицы, если есть.

## Обязательные листы

- `i` — назначение, правила работы, описание листов, история версий.
- `План` — задачи, владельцы, сроки, статусы, результаты.
- `RACI` — зоны ответственности.
- `Риски` — реестр рисков.
- `Приемка` — критерии готовности.

## Проверка результата

Файл должен открываться как `.xlsx`, содержать все обязательные листы, иметь версию `1.0` на листе `i` и не использовать макросы или внешние ссылки.
