# spreadsheet-maker

Создатель таблиц по документации, шаблону или бизнес-задаче.

## Задача

Спроектировать структуру таблицы: листы, колонки, формулы, проверки, источники данных и правила использования.

## Когда нужен SDK

SDK нужен, если таблицы нужно регулярно создавать по шаблонам, проверять структуру или обрабатывать набор файлов.

## Первый результат

Описание таблицы в Markdown или CSV/JSON-спецификация. Генерацию `.xlsx` лучше добавить отдельным этапом.

## Входные данные

- Папка с документацией по таблицам.
- Цель таблицы.
- Пользователь таблицы.
- Пример существующей таблицы, если есть.
