# Eval checklist

- Понятно, зачем нужна таблица.
- Листы и колонки не дублируют друг друга.
- Формулы описаны явно.
- Есть проверки ошибок ввода.
- Есть разделение данных, расчётов и отчётов.
- Пользователь сможет пользоваться таблицей без разработчика.
- Файл создан в формате `.xlsx`.
- Первый лист называется `i`.
- Есть история версий с `v1.0`.
- Есть листы `План`, `RACI`, `Риски`, `Приемка`.
- Нет макросов и внешних ссылок.
- Файл открывается программно без ошибки.
