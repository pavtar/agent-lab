# Eval checklist

- [ ] Есть короткий вывод для руководителя.
- [ ] Все выводы опираются на данные.
- [ ] План/факт и отклонения объяснены.
- [ ] Денежные риски выделены отдельно.
- [ ] Нет доступа к production-финансам без отдельного решения.
- [ ] Есть список данных, которые нужно проверить человеком.
