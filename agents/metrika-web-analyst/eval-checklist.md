# Eval checklist

- [ ] Есть короткий вывод для руководителя.
- [ ] Факты отделены от гипотез.
- [ ] Указаны источники трафика и проблемные сегменты.
- [ ] Данные отфильтрованы по визитам людей без роботов: `ym:s:isRobot=='No'`.
- [ ] Есть отдельный SEO-срез: органика, поисковые фразы, посадочные страницы, устройства.
- [ ] Если SEO-данных нет, это указано как ограничение, без выдуманных фраз и страниц.
- [ ] Есть 3-5 действий на следующую неделю.
- [ ] SEO-действия отделены от рекламных и общих маркетинговых действий.
- [ ] Указаны ограничения данных.
- [ ] Не раскрыты токены и секреты.
- [ ] Отчёт сохранён в Obsidian.
- [ ] В отчёте есть `agentId`, `runId`, период и counter id.
