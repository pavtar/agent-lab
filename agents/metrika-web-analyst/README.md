# metrika-web-analyst

Еженедельный веб-аналитик и SEO-маркетолог по данным Яндекс.Метрики.

## Задача

Собрать данные по трафику, источникам, UTM, поисковым системам и конверсиям, затем сохранить управленческий отчёт в Obsidian.

## Фильтр данных

Все отчёты агента строятся только по визитам людей: роботный трафик исключается фильтром Метрики `ym:s:isRobot=='No'`.

## SEO-блок

Агент отдельно анализирует:

- поисковые системы;
- поисковые фразы, если их вернул API Метрики;
- органические посадочные страницы;
- органику по устройствам;
- ограничения данных: sampling, пустые SEO-отчёты, отсутствие целей.

## Когда нужен SDK

SDK нужен, потому что агент работает регулярно, получает данные из API и должен сохранять отчёт с `agentId`, `runId`, периодом и ограничениями данных.

## Команды

```bash
npm run metrika:counters
npm run agent:metrika
npm run agent:run -- metrika-web-analyst
```

## Входные данные

- `CURSOR_API_KEY`
- `YANDEX_METRIKA_TOKEN`
- `YANDEX_METRIKA_COUNTER_ID`
- `YANDEX_METRIKA_GOAL_IDS`

## Выход

Markdown-отчёт в `../Company OS/Run Logs/`.

Отчёт должен содержать отдельный раздел по SEO: что происходит с органикой, какие страницы или фразы требуют проверки и какие действия сделать на следующей неделе.
