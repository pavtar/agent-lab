Эта база знаний нужна для агента `toyota-kata-coach` и для руководителей, которые хотят применять Toyota Kata в регулярном менеджменте.

## Источники

Исходные PDF хранятся внутри проекта:

```text
knowledge/toyota-kata/sources/Часть I Начало работы.pdf
knowledge/toyota-kata/sources/Часть II Практические методы Ката Совершенствования.pdf
knowledge/toyota-kata/sources/Часть III Ката Коучинга.pdf
```

Это публичные материалы по Ката Совершенствования и Ката Коучинга Майка Ротера. Markdown-файлы в этой папке — рабочая выжимка для применения в компании.

## Принцип

Toyota Kata не заменяет управление и не даёт готовые решения. Она тренирует способ мышления: двигаться к целевому состоянию через факты, препятствия, короткие эксперименты и регулярное обучение.
