# 09. Kata Assistant для новичков

## Назначение

`kata_assistant` — справочный сценарий агента `toyota-kata-coach` для руководителей, которые только начинают практиковать Toyota Kata.

Он нужен, когда пользователь ещё не понимает, какой сценарий выбрать, путается в понятиях или хочет короткое объяснение методологии.

## Что делает kata_assistant

- Объясняет Toyota Kata простым языком.
- Показывает разницу между Improvement Kata и Coaching Kata.
- Объясняет термины: challenge, current condition, target condition, obstacle, experiment, PDCA, learner, coach.
- Помогает выбрать следующий сценарий агента.
- Подсказывает, какой файл базы знаний прочитать.
- Помогает сформулировать первый черновик понятия, но не проводит полноценную сессию вместо специализированного сценария.

## Что не делает kata_assistant

- Не проводит полноценный коучинг-цикл вместо `weekly_coaching`.
- Не тренирует вопросы руководителя вместо `manager_training`.
- Не разбирает бизнес-проблему до canvas вместо `problem_improvement`.
- Не пишет playbook внедрения команды вместо `team_playbook`.
- Не превращает ответ в длинную лекцию.

## Карта выбора сценариев

| Запрос пользователя | Сценарий |
| --- | --- |
| "Я не понимаю, что такое target condition" | `kata_assistant` |
| "Помоги выбрать, с чего начать" | `kata_assistant` |
| "Хочу потренироваться задавать вопросы сотруднику" | `manager_training` |
| "Нужно провести еженедельную сессию по карте ученика" | `weekly_coaching` |
| "Есть проблема в процессе, помоги разобрать" | `problem_improvement` |
| "Хочу внедрить Kata в команде" | `team_playbook` |

## Базовые объяснения

### Toyota Kata

Toyota Kata — практика развития научного мышления в управлении. Она помогает двигаться к целевому состоянию через факты, препятствия и короткие эксперименты.

### Improvement Kata

Improvement Kata — модель улучшения процесса:

1. Понять направление или challenge.
2. Понять текущее состояние.
3. Установить следующее целевое состояние.
4. Двигаться к нему через эксперименты.

### Coaching Kata

Coaching Kata — способ обучать Improvement Kata через 5 вопросов. Коуч не решает задачу за ученика, а помогает увидеть мышление ученика и удержать его в научной модели.

### Challenge

Challenge — направление или вызов. Он объясняет, зачем мы улучшаем процесс, но не диктует готовое решение.

### Current condition

Current condition — фактическое состояние сейчас: данные, наблюдения, метрики, примеры. Это не мнение и не обвинение.

### Target condition

Target condition — ближайшее целевое состояние процесса. Это описание состояния на дату, а не список действий.

### Obstacle

Obstacle — препятствие, которое мешает достичь target condition. В работе должен быть один obstacle, иначе фокус распадается.

### Next experiment

Next experiment — маленький проверяемый шаг: гипотеза, действие, ожидаемый результат и дата проверки.

## Формат ответа kata_assistant

Ответ должен быть коротким:

1. Короткий ответ на вопрос.
2. Простое объяснение через Toyota Kata.
3. Что важно не перепутать.
4. Какой сценарий использовать дальше.
5. Какие файлы базы знаний прочитать.
