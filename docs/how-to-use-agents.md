# Как пользоваться агентами без терминала

Этот playbook нужен для обычной работы с агентами через Cursor Agent, когда не хочется запускать команды и разбираться в SDK.

## Коротко

Если нужно спросить совет, провести интерактивную сессию или подготовить черновик документа, используйте Cursor Agent в интерфейсе.

SDK нужен позже: для регулярных отчётов, API, расписания, сохранения в Obsidian и повторяемой автоматизации.

## Быстрый маршрут

1. Определите, что хотите получить.
2. Выберите агента в `../Company OS/Agents/` (черновики — в `../Company OS/Agents/Draft/`).
3. Выберите сценарий, если у агента их несколько.
4. Откройте новый чат Cursor Agent.
5. Скопируйте стартовый prompt из карточки агента или из этого playbook.
6. Задайте свой вопрос или приложите входные данные.
7. Если результат важный, проверьте его по `agents/<agent-name>/eval-checklist.md` (для черновиков путь: `agents/draft/<agent-name>/eval-checklist.md`).

Для пользователя главным входом является `Company OS/Agents/`. Папка `agent-lab/agents/` нужна, когда вы улучшаете самого агента: prompt, skill, конфиг или checklist.

## Шаблон ручного запуска

Черновики агентов лежат в `agents/draft/<имя>/` — в шаблоне ниже подставьте этот путь вместо `agents/<agent-name>/`, если открыли карточку из `Company OS/Agents/Draft/`.

```text
Работай как агент <agent-name>.
Используй инструкции из agents/<agent-name>/prompt.md.
Сценарий: <scenario-name>.

Моя задача:
...
```

## Пример: совет по Toyota Kata

Используйте, когда нужно спросить методический совет, разобраться в терминах или понять, какой сценарий выбрать.

```text
Работай как агент toyota-kata-coach.
Используй инструкции из agents/toyota-kata-coach/prompt.md.
Сценарий: kata_assistant.

Мой вопрос:
Мне нужен совет по Toyota Kata. С чего начать внедрение в команде руководителей?
```

## Сценарии toyota-kata-coach

- `kata_assistant` — справочный помощник и навигатор по Toyota Kata.
- `manager_training` — тренажёр коучинговых вопросов для руководителя.
- `weekly_coaching` — еженедельная коучинг-сессия по Карте событий ученика.
- `problem_improvement` — разбор бизнес-проблемы через challenge, current condition, target condition, obstacles и next experiment.
- `team_playbook` — playbook внедрения Toyota Kata в регулярный менеджмент команды.

## Когда переходить к SDK

Переходите к SDK, если агент должен:

- запускаться регулярно;
- брать данные из API или файлов;
- сохранять отчёт в `Company OS/Run Logs/`;
- логировать запуск;
- работать одинаково каждую неделю;
- создавать повторяемые артефакты: отчёты, таблицы, презентации или PR.

Практическое правило:

```text
Разовый разговор или интерактивная сессия -> Cursor Agent.
Повторяемый бизнес-процесс -> Cursor SDK.
```

## Как улучшать агента после запуска

Если результат слабый, не нужно сразу переделывать всё.

Проверьте:

1. Был ли выбран правильный агент.
2. Был ли выбран правильный сценарий.
3. Были ли даны достаточные входные данные.
4. Нужно ли уточнить `agents/<agent-name>/prompt.md`.
5. Нужно ли улучшить skill в `skills/`.
6. Нужно ли добавить знания в `knowledge/`.

Если после улучшения агента изменился способ запуска, сценарии или ограничения, обновите карточку в `../Company OS/Agents/`. Это часть операционной модели, а не отдельная задача для пользователя.
