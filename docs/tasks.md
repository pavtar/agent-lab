# Задачи для первых агентов

## Очередь

- [ ] Изучить структуру репозитория и объяснить её простым языком.
- [ ] Предложить улучшения для `README.md`.
- [ ] Создать шаблон отчёта о запуске агента.
- [ ] Проверить Pull Request и выписать риски для руководителя.

## Правила постановки задач

Каждая задача должна содержать:

- цель;
- входные данные;
- разрешённые действия;
- запрещённые действия;
- критерий готовности;
- кто проверяет результат.
