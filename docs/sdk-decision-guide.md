# Когда нужен Cursor SDK

Cursor SDK нужен не для обычного общения с агентом, а для повторяемой автоматизации.

## Можно без SDK

Используйте обычный Cursor Agent в интерфейсе, если:

- задача разовая;
- вы вручную пишете задачу агенту в Cursor;
- нужно объяснить код, улучшить документ или задать вопрос;
- результат можно проверить прямо в чате;
- нет необходимости сохранять отчёт в заданный файл;
- нет внешних API, расписания и логирования.

Пример: «Посмотри этот README и предложи улучшения».

## Нужен SDK

Используйте Cursor SDK, если агент:

- запускается регулярно;
- получает данные из API, CRM, Метрики, рекламных кабинетов или файлов;
- должен сохранять отчёт в Obsidian;
- должен логировать `agentId`, `runId`, статус, период и входные данные;
- должен работать одинаково каждую неделю;
- запускается из скрипта, GitHub Actions, backend-сервиса или внутренней панели;
- создаёт артефакты: Markdown-отчёт, таблицу, презентацию, Pull Request.

Пример: «Каждый понедельник собрать Яндекс.Метрику, проанализировать и сохранить отчёт в Obsidian».

## Практическое правило

```text
Разовая ручная задача -> Cursor Agent в интерфейсе.
Повторяемый бизнес-процесс -> Cursor SDK.
```

## Как применять к нашим агентам


| Агент                      | SDK нужен?         | Причина                                                              |
| -------------------------- | ------------------ | -------------------------------------------------------------------- |
| `metrika-web-analyst`      | Да                 | API Метрики, еженедельный отчёт, Obsidian                            |
| `meeting-secretary`        | Да, если регулярно | Транскрипты, протоколы, задачи                                       |
| `business-system-analyst`  | Иногда             | Для разовых ТЗ хватит Cursor Agent, для пакетной обработки нужен SDK |
| `process-architect`        | Иногда             | Первая версия ручная; SDK нужен, если карты собираются регулярно по шаблону |
| `brand-presentation-maker` | Частично           | SDK нужен для повторяемой генерации по бренд-документации            |
| `spreadsheet-maker`        | Частично           | SDK нужен для генерации и проверки файлов                            |
| `finance-director`         | Да                 | Регулярные данные, расчёты, контроль качества                        |
