# Примеры управленческих Excel-книг

В этой папке лежат примеры `.xlsx`-файлов, которые можно использовать как образцы для постановки задач агенту.

## Файлы

- `Пример - редизайн сайта site.ru по SDD v1.1.xlsx` - актуальный пример книги для проекта редизайна сайта по методологии SDD.
- `Пример - редизайн сайта site.ru по SDD v1.0.xlsx` - предыдущая версия примера.

## Как использовать

1. Откройте пример в Excel или Google Sheets.
2. Посмотрите структуру листов, вводный лист `i`, историю версий, план, RACI, риски и приемку.
3. Используйте `excel-workbook-generation-guide.md` из корня проекта, чтобы поставить агенту задачу на создание аналогичной книги под свой проект.
